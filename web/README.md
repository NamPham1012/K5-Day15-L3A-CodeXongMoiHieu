# Trang demo CP2: kiểm tra lịch thuê

- Chạy: `python web/server.py` (thêm `--port 9000` nếu cần), rồi mở http://127.0.0.1:8765
- In bảng ca thử trong terminal: `python web/scenarios.py`
- Chỉ dùng thư viện chuẩn Python; không sửa file ngoài `web/`; không ghi trace hay eval.
- Mọi kết quả và đạt/trượt tính lại từ `codebase/` mỗi lần chạy. Data tạm chỉ nằm trong bộ nhớ.
- Ảnh chụp (nếu có) ở `web/shots/`, không commit.
